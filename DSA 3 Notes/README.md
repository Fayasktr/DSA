# DSA 3 Master Notes Repository

Welcome to the comprehensive Data Structures and Algorithms (DSA) notes repository. This repository contains detailed explanations, conceptual breakdowns, and practical implementation details for advanced data structures covered in DSA 3.

## Structure

- **Trees**: Binary Search Trees (BST), AVL Trees, Red-Black Trees, Segment Trees.
- **Graphs**: Traversals (BFS/DFS), Cycle Detection, Shortest Path algorithms, Minimum Spanning Trees (MST).
- **Heaps**: Min/Max Heaps, Heap Sort, Priority Queues.
- **Trie**: Prefix Tries, Suffix Tries, Autocomplete implementations.
- **Complexity**: Big-O notation, Time and Space complexity analysis.
- **LeetCode**: Problems and patterns based on Blind 75, graph, and tree problems.

Each topic folder contains detailed `.md` files answering key conceptual and practical questions.
