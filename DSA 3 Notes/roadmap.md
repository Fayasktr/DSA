# DSA 3 Learning Roadmap

## Phase 1: Trees and Binary Search Trees (BST)
1. **Tree Basics**: Understand terminologies (root, node, leaf, edge, depth, height, degree).
2. **Types of Trees**: Binary Tree, Full, Perfect, Complete, Degenerate, N-ary Tree.
3. **Binary Search Tree (BST)**: Core concepts, insertion, deletion, and searching.
4. **Traversals**: DFS (Inorder, Preorder, Postorder) and BFS (Level order traversal).
5. **Advanced Tree Operations**: Finding Nth largest/smallest, Lowest Common Ancestor (LCA), Validating BST.
6. **Self-Balancing Trees**: Introduction to AVL Trees and Red-Black Trees.

## Phase 2: Graphs
1. **Graph Fundamentals**: Types (Directed/Undirected, Weighted/Unweighted), Terminologies (Vertex, Edge, Degree, Adjacency).
2. **Graph Representation**: Adjacency Matrix vs. Adjacency List.
3. **Graph Traversals**: Breadth-First Search (BFS) and Depth-First Search (DFS).
4. **Cycle Detection**: Detecting cycles in Directed and Undirected graphs.
5. **Shortest Path Algorithms**: Dijkstra's Algorithm, Shortest path in unweighted graphs.
6. **Spanning Trees**: Minimum Spanning Tree (MST) algorithms (Kruskal's and Prim's).

## Phase 3: Heaps & Priority Queues
1. **Heap Basics**: Max-Heap and Min-Heap properties. Array representation of Heaps.
2. **Heap Operations**: Insertion, Deletion (extract max/min), and Heapify (Up/Down).
3. **Heap Sort**: Sorting an array using Heap Sort. Time complexity analysis.
4. **Priority Queue**: Implementing Priority Queue using Heaps. Applications of Priority Queues.

## Phase 4: Trie (Prefix Tree)
1. **Trie Concept**: Structure, Insertion, Searching (prefix and exact match).
2. **Applications of Trie**: Autocomplete, Spell Checker, Longest Common Prefix.
3. **Variants**: Suffix Trie, Compressed Trie.

## Phase 5: Complexity Analysis & Optimization
1. **Big-O Notation**: Best, Worst, and Average case time complexity.
2. **Space Complexity**: Auxiliary space vs space complexity.
3. **Algorithms**: Sliding Window, Two Pointers, Backtracking, Recursion vs Iteration.
