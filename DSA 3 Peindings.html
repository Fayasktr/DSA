DSA 3 Master Reference

Simple, beginner-friendly explanations for complex Data Structures and Algorithms.

Hierarchy Non-Linear

🌲 Trees

Short Definition

A tree is a data structure made of nodes connected by edges. It looks like an upside-down real tree with a root at the top and leaves at the bottom.

Simple Explanation

Imagine your computer's file folder system. You have a main drive (root), folders inside it (branches), and files inside those folders (leaves). A tree organizes data hierarchically, not in a straight line like an array.

Key Points

  • Root: The top node.
  • Leaf: A node with no children.
  • Height: Longest path from root to a leaf.

Small Example: A family tree. Grandparent -> Parents -> Children.

Common Interview Question: What is the difference between height and depth of a tree?

Important Note: Trees cannot have cycles (loops). If they do, they are graphs!

Searching Binary Tree

🔍 Binary Search Tree (BST)

Short Definition

A binary tree where the left child is always smaller than the parent, and the right child is always greater.

Simple Explanation

Like a dictionary. If you search for "Mango" and you open to "Peach", you know you only need to look at the left half. A BST automatically halves your search area every step.

Time Complexity

OperationAverageWorst Case
Search / Insert / DeleteO(log N)O(N)

Small Example: Array [5, 3, 7]. 5 is root. 3 goes left. 7 goes right.

Common Interview Question: Find the Kth smallest element in a BST. (Hint: Inorder traversal).

Important Note: If you insert an already sorted array into a BST, it becomes a straight line (Linked List) and takes O(N) time.

Self-Balancing BST

⚖️ AVL Tree

Short Definition

A smart Binary Search Tree that automatically balances itself so it never becomes a straight line.

Simple Explanation

If one side of the tree gets too heavy (height difference > 1), the tree performs a "rotation" to balance the weight. This guarantees operations stay fast.

Time Complexity

OperationTime Complexity
Search / Insert / DeleteStrictly O(log N)

Key Points: Balance factor must be -1, 0, or 1.

Common Interview Question: What are the 4 types of rotations in an AVL tree? (LL, RR, LR, RL).

Important Note: AVL trees are better for reading data. Red-Black trees are better if you do lots of inserting/deleting.

Priority Complete Tree

⛰️ Heap

Short Definition

A tree-based structure (stored in an array) where the parent is always bigger (Max-Heap) or smaller (Min-Heap) than its children.

Simple Explanation

Imagine a hospital ER. Patients aren't treated in the order they arrive; they are treated by priority. A Max-Heap always keeps the highest priority item at the very top for instant access.

Time Complexity

OperationTime Complexity
Peek Max/MinO(1)
Insert / ExtractO(log N)

Small Example: Min Heap: Parent is 5, children are 10 and 20.

Common Interview Question: Find the Top K frequent elements in an array. (Use a Min-Heap of size K).

Important Note: Heaps are almost always implemented using flat Arrays using math formulas to find children.

Sorting In-Place

🔄 Heap Sort

Short Definition

A sorting algorithm that turns the array into a Heap, extracts the largest item, and puts it at the end of the array repeatedly.

Simple Explanation

It's like finding the tallest person in a room, asking them to stand at the back, and repeating this for the rest of the room until everyone is sorted by height.

Time Complexity

OperationTime Complexity
Building HeapO(N)
SortingO(N log N)

Common Interview Question: Is Heap Sort a stable sort? (No, it can change the relative order of equal items).

Important Note: It uses O(1) space, making it very memory efficient.

Strings Prefix Tree

🔤 Trie (Prefix Tree)

Short Definition

A tree specialized for storing words. Words that share the same starting letters share the same nodes.

Simple Explanation

Think of your phone's autocomplete. If you type "C-A-R", the Trie quickly pulls up "Card", "Cart", and "Carrot" because they all live on the same branch.

Time Complexity

OperationTime Complexity
Insert / Search StringO(L) - where L is word length

Small Example: "cat" and "car" share the 'c' and 'a' nodes.

Common Interview Question: Implement an autocomplete system.

Important Note: Tries are super fast but consume a lot of memory (each node needs 26 pointers for alphabet).

Networks Nodes & Edges

🕸️ Graph

Short Definition

A collection of nodes (vertices) connected by lines (edges). They can be directed (one-way) or undirected.

Simple Explanation

Facebook is a graph. You are a node, your friend is a node, and your friendship is the edge connecting you.

Key Points

  • Weighted: Edges have distance/cost (like Google Maps).
  • Cycle: Starting at one node and walking in a loop back to it.

Common Interview Question: How do you represent a graph in code? (Adjacency List or Adjacency Matrix).

Important Note: Trees are just special types of graphs that have no cycles.

Traversal Level by Level

🌊 Breadth-First Search (BFS)

Short Definition

A graph search algorithm that looks at all immediate neighbors first before moving deeper.

Simple Explanation

Like dropping a stone in water. The search expands outwards in ripples. It uses a Queue (First In, First Out) to remember where to go next.

Time Complexity

O(V + E) where V = Vertices, E = Edges.

Applications: Finding the shortest path in an unweighted graph, finding mutual friends.

Important Note: You MUST use a "visited" array, otherwise you will get stuck in an infinite loop if there's a cycle.

Traversal Go Deep

🚀 Depth-First Search (DFS)

Short Definition

A graph search algorithm that goes as deep down one path as possible before backing up.

Simple Explanation

Like walking through a maze. You keep your hand on one wall and walk until you hit a dead end, then you walk backwards to the last turn. It uses a Stack (or Recursion).

Time Complexity

O(V + E)

Applications: Solving mazes, detecting cycles, Topological Sorting.

Common Interview Question: Detect a cycle in a directed graph. (Hint: use a recursion stack).

Greedy Weighted Graphs

🛤️ Minimum Spanning Tree (MST)

Short Definition

A subset of graph edges that connects all nodes together without any cycles, using the minimum possible total edge weight.

Simple Explanation

Imagine you have to connect 5 cities with fiber-optic cables. You want all cities connected, but you want to spend the least amount of money on cables. The MST gives you that layout.

Key Algorithms

  • Kruskal's: Sort edges by weight, add cheapest ones first (if no cycle).
  • Prim's: Start at one node, grow outward by always picking the cheapest connecting edge.

Important Note: An MST has exactly (Vertices - 1) edges.

Performance Big-O

⏱️ Complexity Analysis

Short Definition

Big-O notation is how we describe the worst-case speed or memory usage of an algorithm as the input gets bigger.

Simple Explanation

If you have to wash 1 plate, it takes 1 minute. If you wash 10 plates, it takes 10 minutes. That's O(N) or linear time. It grows directly with the size.

Common Speeds (Fast to Slow)

  • O(1) Constant: Array lookup. Instant.
  • O(log N) Logarithmic: Binary Search. Very fast for big data.
  • O(N) Linear: Normal loop.
  • O(N log N): Good sorting (Merge sort, Heap sort).
  • O(N²): Nested loops (Bubble sort). Slow.
