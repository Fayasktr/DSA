1. Introduction to Graphs

A Graph is a non-linear data structure consisting of nodes (or vertices) and edges that connect these nodes. Graphs are fundamentally used to represent networks like city roads, social media connections, or computer networks.

Formal Definition: A graph G is an ordered pair G = (V, E) where V is a set of vertices (nodes) and E is a set of edges connecting pairs of vertices.

1.1 Basic Terminology

Vertex (Node)

The fundamental unit of a graph. It holds data.

Edge (Link)

The connection between two vertices.

Degree of a Vertex

The number of edges connected to a vertex. In directed graphs, split into in-degree (incoming) and out-degree (outgoing).

Path

A sequence of vertices where each adjacent pair is connected by an edge.

1.2 Types of Graphs

  • Directed Graph (Digraph): Edges have a specific direction (A → B). Like Twitter followers.
  • Undirected Graph: Edges have no direction (A — B). Like Facebook friends.
  • Weighted Graph: Edges have a value (weight or cost) associated with them. E.g., distance between cities.
  • Unweighted Graph: Edges have no weight (assumed uniform cost).
  • Cyclic Graph: Contains at least one graph cycle (a path that starts and ends on the same vertex).
  • Acyclic Graph: Contains no cycles. (e.g., Directed Acyclic Graph - DAG).
  • Complete Graph: Every pair of distinct vertices is connected by a unique edge. (Edges = n*(n-1)/2).
  • Disconnected Graph: There is at least one pair of vertices without a path between them. It consists of multiple connected components.

1.3 Graph vs. Tree

Feature Tree Graph
Structure Hierarchical Network model
Cycles Never contains cycles (Acyclic) Can contain cycles (Cyclic or Acyclic)
Root Node Always has one root node No concept of a root node
Connectivity Always connected Can be disconnected

2. Graph Representation

How do we store graphs in memory? There are two primary methods used in implementation.

2.1 Adjacency Matrix

A 2D array of size V x V where V is the number of vertices. If adj[i][j] == 1, there is an edge from vertex i to vertex j.

  • Space Complexity: O(V²) - Not efficient for sparse graphs.
  • Checking Edge Existence: O(1) - Very fast.
  • Finding Neighbors: O(V) - Have to scan the whole row.

class GraphMatrix {
    constructor(numVertices) {
        this.numVertices = numVertices;
        // Initialize a V x V matrix with 0s
        this.matrix = Array(numVertices).fill().map(() => Array(numVertices).fill(0));
    }

    addEdge(v1, v2) {
        this.matrix[v1][v2] = 1;
        this.matrix[v2][v1] = 1; // For undirected graph
    }
}

2.2 Adjacency List (Most Common)

An array (or Map/Dictionary) of lists. The index represents the vertex, and the list at that index contains all its adjacent vertices.

  • Space Complexity: O(V + E) - Highly efficient for sparse graphs.
  • Finding Neighbors: Fast, just iterate through the specific list.

class GraphList {
    constructor() {
        this.adjList = new Map(); // Using Map to handle any type of vertex (string, number, object)
    }

    addVertex(vertex) {
        if (!this.adjList.has(vertex)) {
            this.adjList.set(vertex, []);
        }
    }

    addEdge(v1, v2) {
        // Assume unweighted, undirected graph
        this.adjList.get(v1).push(v2);
        this.adjList.get(v2).push(v1); 
    }
}

3. Graph Traversal

Traversal means visiting every vertex in the graph. Unlike trees, graphs can have cycles, so we must track visited nodes to avoid infinite loops.

Interactive Traversal Visualization

3.1 Breadth-First Search (BFS)

Explores the graph level by level. It uses a Queue (FIFO) data structure. Excellent for finding the shortest path in unweighted graphs.


function BFS(startVertex, adjList) {
    let visited = new Set();
    let queue = [startVertex]; // Initialize queue with start node
    let result = [];

    visited.add(startVertex);

    while (queue.length > 0) {
        let current = queue.shift(); // Dequeue (remove from front)
        result.push(current);

        // Get all neighbors of current vertex
        let neighbors = adjList.get(current) || [];
        
        for (let neighbor of neighbors) {
            if (!visited.has(neighbor)) {
                visited.add(neighbor);
                queue.push(neighbor); // Enqueue unvisited neighbors
            }
        }
    }
    return result;
}

3.2 Depth-First Search (DFS)

Goes as deep as possible down one path before backtracking. Uses a Stack (LIFO) or recursion. Good for detecting cycles, topological sorting, and solving puzzles (backtracking).


function DFS(startVertex, adjList) {
    let visited = new Set();
    let result = [];

    // Recursive helper function
    function dfsHelper(vertex) {
        visited.add(vertex);
        result.push(vertex);

        let neighbors = adjList.get(vertex) || [];
        for (let neighbor of neighbors) {
            if (!visited.has(neighbor)) {
                dfsHelper(neighbor); // Recursive call to go deep
            }
        }
    }

    dfsHelper(startVertex);
    return result;
}

4. Advanced Concepts & Algorithms

4.1 Detecting Cycles in a Graph

In Undirected Graphs

Use DFS or BFS. Keep track of the parent node. If you visit a node that is already visited AND is not the parent of the current node, a cycle exists.

In Directed Graphs

Use DFS. Keep track of a recursion stack (or path visited in current DFS call). If you encounter a node already in the current recursion stack, a back-edge exists, meaning there is a cycle.

4.2 Shortest Path Algorithms

  • BFS: Best for unweighted graphs to find shortest distance between vertices.
  • Dijkstra's Algorithm: For graphs with non-negative weights. Uses a priority queue/min-heap to constantly pick the node with the smallest known distance.
  • Bellman-Ford Algorithm: Can handle negative weights and detect negative weight cycles. Slower than Dijkstra (O(V*E)).
  • Floyd-Warshall Algorithm: All-pairs shortest path. Dynamic programming approach (O(V³)).

4.3 Minimum Spanning Tree (MST)

A subgraph that connects all vertices without any cycles and with the minimum possible total edge weight. (Used in network design, laying cables).

Prim's Algorithm

Starts with a single node, grows the MST by greedily picking the smallest edge connecting a visited node to an unvisited node. (Uses Priority Queue).

Kruskal's Algorithm

Sorts all edges by weight. Greedily adds the smallest edge to the MST unless it forms a cycle. (Uses Disjoint Set / Union-Find data structure).

4.4 Bipartite Graph

A graph whose vertices can be divided into two disjoint sets U and V such that every edge connects a vertex in U to one in V. (Graph Coloring: Can it be colored with just 2 colors without adjacent nodes having the same color?)

4.5 Tarjan's Algorithm & Strongly Connected Components (SCC)

In a directed graph, an SCC is a portion where every vertex is reachable from every other vertex in that portion. Tarjan's uses DFS, keeping track of discovery times and lowest reachable discovery times to find SCCs in O(V+E) time.

5. Graph Applications in Real Life

Maps & Navigation

Google Maps uses Graphs. Intersections are nodes, roads are edges. Dijkstra/A* finds the shortest route.

Social Networks

"Mutual friends" features or connection suggestions (LinkedIn) use BFS to find friends of friends.

Computer Networks

Routing protocols use algorithms like Bellman-Ford to find paths for data packets.

Web Crawlers

Search engines use graph traversal to follow links (edges) from one webpage (node) to another.

Task Scheduling

Resolving dependencies (e.g., compiling code, taking prerequisite courses) using Topological Sorting on a DAG.

Solving Puzzles

Problems like "Number of Islands" (matrix traversal) or solving Sudoku use DFS and Backtracking.
